# Neural Network Modeling of Psychoactive Drug Pharmacodynamics

Neural network modeling of psychoactive drug pharmacodynamics, receptor activity, and addiction mechanisms using reinforcement learning.

## Quick Start

## Project Structure

- **paper/** – Research paper on pharmacodynamic modeling
- **models/** – Neural network architectures, receptor binding models, addiction mechanisms
- **simulations/** – RL environments, dose-response curves, addiction progression
- **data/** – Pharmacological datasets, receptor activity data, clinical outcomes
- **docs/** – Pharmacology background, NN architecture justification, RL formulation

## Key Features

- Receptor-level pharmacodynamics
- Neural network-based dose-response modeling
- Reinforcement learning for addiction dynamics
- Time-dependent receptor dynamics
- Multi-drug interaction modeling
